```
Fases del comisionamiento según ISO 16530-1:

1. Planificación
2. Pre-comisionamiento (limpieza, pruebas hidrostáticas, secado)
3. Comisionamiento (verificación funcional, calibración)
4. Puesta en marcha (arranque, estabilización)
5. Pruebas de desempeño

Cada fase tiene entregables específicos que deben documentarse.
```

## Gestión de Activos y Mantenimiento

```
ISO 55000 - Conceptos fundamentales

Activo: elemento que tiene valor potencial o real para una organización
Gestión de activos: actividad coordinada para extraer valor de los activos
Sistema de gestión de activos: conjunto de elementos interrelacionados para establecer políticas, objetivos y procesos

Diplomado con certificación IAM: abril 2026
```

```
RCM - Las 7 preguntas básicas

1. ¿Cuáles son las funciones del activo?
2. ¿De qué manera puede fallar en cumplir sus funciones?
3. ¿Qué causa cada falla funcional?
4. ¿Qué sucede cuando ocurre cada falla?
5. ¿Cuáles son las consecuencias de cada falla?
6. ¿Qué se puede hacer para predecir o prevenir cada falla?
7. ¿Qué se debe hacer si no se encuentra una tarea proactiva adecuada?
```

# NOTAS

Los posts están escritos para informar. Sin hooks, sin preguntas retóricas, sin llamados a la acción agresivos.

El tono es el de un boletín técnico o un comunicado institucional. Similar a como publica ASME, API o una empresa como Ecopetrol.

Los temas varían para mostrar la amplitud del portafolio: seguridad de procesos, integridad, mantenimiento, gas, oil & gas, gestión de activos.

Las publicaciones de actividad (cursos completados) se escriben como un registro: qué, quién, cuándo, dónde.

Los webinars y eventos se anuncian con información básica: tema, fecha, hora, link.
