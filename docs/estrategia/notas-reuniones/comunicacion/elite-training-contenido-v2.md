## SERIE NFPA 652

### Post 1

```
NFPA 652 edición 2023

Cambios principales respecto a 2019:

→ DHA obligatorio para cualquier proceso con polvo combustible
→ Responsabilidad explícita del owner/operator en documentación y trazabilidad
→ Integración formal con gestión del cambio (MOC)
→ Requisitos de housekeeping cuantificables

La norma no agregó requisitos técnicos nuevos. Clarificó quién es responsable de qué.

Más información: nfpa.org/652
```

---

### Post 2

```
Dust Hazard Analysis (DHA) bajo NFPA 652

Requisitos mínimos:

1. Alcance documentado (proceso, equipos, interconexiones)
2. Metodología justificada por escrito
3. Revisión cuando hay cambios de material, equipo o parámetros
4. Conexión con sistema de MOC

Un DHA que no se actualiza cuando cambia el proceso no cumple con la norma.
```

---

### Post 3

```
MOC y NFPA 652

La edición 2023 establece que cualquier modificación de materiales, equipos o parámetros de operación requiere reevaluación del análisis de riesgo de polvo combustible.

Cambios que disparan revisión:
- Proveedor de material (aunque la especificación sea "equivalente")
- Parámetros de proceso (velocidad, temperatura, humedad)
- Frecuencia o método de limpieza
- Configuración de equipos

Si tu sistema de MOC no pregunta por impacto en DHA, hay un gap.
```

---

### Post 4

```
Housekeeping bajo NFPA 652 2023

La norma requiere:
- Límites de acumulación definidos por zona (espesor máximo en mm)
- Frecuencia de limpieza basada en tasa de acumulación real
- Método de verificación documentado

"Mantener limpio" no es un criterio auditable.
```

---

### Post 5

```
NFPA 652 y normas sectoriales

NFPA 652 es el marco general para polvo combustible. No reemplaza normas específicas:

- Metales combustibles → NFPA 484
- Agricultura y alimentos → NFPA 61  
- Productos de madera → NFPA 664
- Químicos y plásticos → NFPA 654

El DHA debe identificar qué normas específicas aplican a cada proceso.
```

---

### Post 6

```
Auditoría NFPA 652

Lo que revisa un auditor:

1. ¿Existe DHA documentado?
2. ¿Cuándo fue la última actualización?
3. ¿Qué disparó esa actualización?
4. ¿Cómo se conecta con MOC?
5. ¿Quién es responsable de mantenerlo?

La pregunta implícita: ¿el DHA es un documento o un sistema de decisión?
```
