## Importancia de la Exclusividad

| Nivel | Descripción | Ventaja Competitiva |
|-------|-------------|---------------------|
| Exclusivo | Solo trabaja con nosotros | Máxima diferenciación |
| Preferido | Trabaja principalmente con nosotros | Alta diferenciación |
| Compartido | También trabaja con competencia | Menor diferenciación |
| Desconocido | No sabemos | Por investigar |

## Información por Instructor

Para cada instructor, documentar:

| Campo | Descripción |
|-------|-------------|
| Cursos | Qué puede dictar |
| Sectores | En cuáles tiene experiencia |
| Exclusividad | Exclusivo, Preferido, Compartido |
| Ubicación | Dónde está basado |
| Estructura de costos | Cómo cobra |
| Clientes que lo piden | Quién lo solicita específicamente |
| Tasa de repetición | % de clientes que repiten con él |
| Fortalezas | Qué lo hace único |
| Disponibilidad | Restricciones de agenda |
